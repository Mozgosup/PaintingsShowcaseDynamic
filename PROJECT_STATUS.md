## **Проект: Paintings Showcase**
### **Текущий статус**
1. **Frontend:**
    - Написан с использованием React.
    - Реализованы основные страницы:
        - `Artworks` для отображения картин.
        - `About Lidia` для биографии с изображениями.
    - Подключен к backend через временную proxy-конфигурацию для локального тестирования.
    - Использует библиотеку `i18next` для переключения языков.

2. **Backend:**
    - Написан на Kotlin с использованием Spring Boot.
    - Реализованы эндпоинты для работы с картинами и биографией:
        - `GET /api/paintings` — получить список картин.
        - `POST /api/paintings/upload` — загрузка новой картины.
        - `GET /api/biography/images` — получение списка изображений для страницы биографии.
    - Интеграция с AWS S3 для хранения изображений.
    - Настроены временные CORS-правила для локального тестирования.

3. **База данных:**
    - Используется PostgreSQL.
    - Миграции настроены с помощью Flyway.

4. **Инфраструктура:**
    - Пока проект запускается локально через IntelliJ IDEA:
        - Frontend на `localhost:3000`.
        - Backend на `localhost:8080`.
    - Настроена proxy-конфигурация для тестирования взаимодействия frontend и backend.

5. **Текущие временные настройки:**
    - **CORS:** Настроен для локального взаимодействия с `http://localhost:3000`.
    - **Proxy:** Используется `proxy` в `package.json` фронтенда для переадресации запросов на backend.
